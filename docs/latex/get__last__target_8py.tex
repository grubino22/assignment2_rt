Description\+: ~\newline
 This node subscribes to the /reaching\+\_\+goal/goal topic to receive the latest target goal and stores it. It provides a service, /get\+\_\+last\+\_\+goal, that returns the last received goal information when requested. The service response contains the position (x, y, z) of the last target goal.
